# 모아콘 사용성 평가·개선과 로컬 네이티브 배포

## 요청
전문가 사용성 평가를 수행하고 RPI와 소크라테스 엘렝코스 검증으로 문제를 직접 개선한 뒤 네이티브 앱을 로컬 빌드·배포한다.

## 분석과 결정
바코드+가격/날짜만으로 일반 바코드가 쿠폰으로 확정되던 분류, 이미지 원본 삭제/유실, 권한 거부 시 보관함 잠금, 읽기 전용 인식 정보, 사용 상태 혼재, 잔액 복원, 삭제 재등장을 수정했다. 불확실 후보는 확인 필요로 보관하고 기존 항목도 삭제 없이 확인을 거치도록 이전한다.

## 구현
- 쿠폰 문맥 기반 분류, 복수 바코드 확인 처리, 브랜드/교환처 파싱, 명시된 유효기간 및 범위 끝 날짜 파싱.
- 로컬 원본 보관과 대기열 분리, 마지막 참조 삭제 시 복사본 정리, 일반 바코드 삭제 후 자동 재등장 방지.
- 권한 독립 보관함, 상태 필터/검색/만료순 정렬, 정보 수정·명시적 승인, 원본 확대, 오류·결과 표시와 스캔 중단.
- 잔액 보존, 유효기간 당일 포함, 저장 실패 rollback, 중복 바코드 수정 차단.
- 모아콘 명칭·문구·M 티켓 앱 아이콘·접근성 글자 크기 레이아웃.
- 시뮬레이터 CPU/legacy barcode revision 설정, DEBUG 전용 격리된 화면 테스트 데이터.
- 재실행 가능한 `scripts/deploy-local.sh`, 개인정보 원칙과 상세 평가 문서 갱신.

## QA
20개 회귀 테스트 + 3개 화면 테스트 통과. Code128+한글 OCR+파싱, 기존 저장소 이전, 원본 보관/삭제, 잔액 및 정보 수정 검증을 포함한다. 시뮬레이터 Release 빌드·설치·실행과 실제 빈 보관함 화면 확인 성공. 큰 글자에서 세로 행동 버튼 확인 후 설정 복원. 최종 iPhone arm64 unsigned Release 빌드 성공.

## 배포 범위와 제한
시뮬레이터 로컬 배포 완료. 실기기 서명은 Xcode 계정 인증 거절과 만료된 프로파일로 차단됐다. 재로그인을 사용자에게 요청했으며, 유효한 프로파일 없이는 설치 완료라고 표시하지 않는다. 실쿠폰 인식률·실매장 판독·VoiceOver·반복사용 선호도는 아직 검증되지 않았다.
