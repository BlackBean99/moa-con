# T03 등록 복구 검증

- 인식 실패 → 브랜드/상품/번호 직접 입력 → 보관 → 상세 원본 열기 UI 테스트 통과(/tmp/moacon-T03.xcresult, 해당 테스트 성공).
- 다중 번호 미선택 저장 차단 → 후보 B 선택 → 실제 상세에 B 번호 저장 UI 테스트 통과(/tmp/moacon-T03-fixed.xcresult).
- 첫 검증에서 오류 문구가 폼 아래에 숨은 문제를 발견. 오류를 시스템 Alert로 표시하고 재검증 통과.
- 사진 데이터는 보관 시 복사. 취소는 파일을 만들지 않으며 DB 저장 실패 시 새 복사본 정리. 후보 번호 중복 검증은 복사 이전 수행.
