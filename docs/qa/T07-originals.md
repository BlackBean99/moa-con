# T07 원본 보존 검증

- 단위 테스트 전체 통과(/tmp/moacon-T07.xcresult): 원본 bytes 복사/조회, 같은 Photos 출처 중복 방지, 복사본과 삭제 제외 상태 유지, 마지막 참조 삭제 확인.
- 자동 찾기는 원본 데이터 복사/검증/파일 저장 후 DB 참조 생성. 기존 Photos 참조는 접근 가능한 원본을 복사하고 실패 시 기존 참조를 보존.
- 금액 의미가 없던 기존 데이터는 차감 이력은 유지하고 미확인 금액을 확인 필요로 보냄.
- iCloud에만 있고 다운로드되지 않은 원본은 자동 찾기에서 보관하지 않으며 일부 처리 실패 표시. 직접 사진 선택으로 가져올 수 있음. 기존 삭제/접근 상실 원본은 과거 복사본이 없으면 복원할 수 없음.
- 실제 Photos 삭제/권한 취소는 T09 기기 QA에서 별도 확인. 이 단위 테스트는 파일 bytes가 Photos 참조 없이 읽히는 경계 증거다.
