# T06 대기 목록 복구 검증

- 네이티브 UI에서 실패 대기 사진 → 직접 입력 → 원본 유지 보관 → 대기 목록 비움 → 상세 원본 접근 테스트 통과(/tmp/moacon-T04-T06.xcresult).
- 대기 목록에 명시적 다시 인식/직접 입력/삭제 제공. 앱 활성화 시 가져오기 결과 표시.
- 수동 등록 DB 실패 시 기존 대기 원본을 Failed로 복구. 삭제는 확인 대화상자 이후 실행.
- 가져오기 대기 목록 로드 오류 처리의 Swift 이름 충돌을 컴파일에서 발견해 self.error로 수정, 후속 빌드/테스트 통과.
