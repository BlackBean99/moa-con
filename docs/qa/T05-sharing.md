# T05 공유 검증

- 읽을 수 없는 파일이 매번 자동 재시도 대기열에 남는 문제를 red 테스트로 재현.
- 변경 후 단위 테스트 전체 통과(/tmp/moacon-T05-green.xcresult). 실패 원본은 Failed 폴더로 이동하며 다음 자동 처리에 포함하지 않음.
- 공유 확장은 파일 크기 먼저 확인하고 20MB/4천만 픽셀 제한, 순차 저장. 성공·실패 수와 실패 항목만 재시도 버튼 제공. 앱/확장 Swift 6 빌드 성공.
- 실제 외부 앱 공유 시트 과업은 T09에서 추가 점검. 강제로 디스크 오류를 발생시키는 실기기 테스트는 미실행.
