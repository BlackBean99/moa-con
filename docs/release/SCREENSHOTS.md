# 스크린샷 준비

metadata.json의 screenshots.iPhone / screenshots.iPad에 저장소 기준 PNG 경로를 기록한다. release-check는 파일 존재, 규격, 투명도를 검사하며 화면의 품질·실제 기능 일치는 사람이 검토한다.

현재 iPhone 17 Pro UI 테스트 캡처는 QA 증거다. 제출 대표 규격용 6.9/6.5인치 및 iPad 13인치 화면은 아직 준비되지 않았다. iPad 지원을 검증 없이 제거하지 않았다.

권장 화면: 만료순 보관함, 원본/사용 번호 확대, 금액권 잔액, 직접 등록/번호 선택. 운영자 연락처나 실제 고객의 사용 가능한 번호는 캡처에 넣지 않는다. fixtures/*.png는 원본 입력용이며 앱 화면을 보여주는 스크린샷이 아니다.

[Apple 규격](https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications)
