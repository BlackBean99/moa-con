# App Store 한국어 자료

이름: 모아콘
부제: 쿠폰을 한곳에
분류 제안: 유틸리티
첫 출시 제안: 한국, 무료, iPhone/iPad. 운영자 확인 전 초안이다.

## 소개

사진으로 받은 쿠폰을 한곳에 보관하세요.

사진을 직접 선택하거나 다른 앱에서 모아콘으로 공유할 수 있습니다. 사진 보관함에서 쿠폰을 찾고, 인식되지 않은 정보는 직접 입력하세요. 여러 바코드가 있으면 사용할 번호를 선택할 수 있습니다.

상품 교환권과 금액권을 나누어 관리하고, 원본을 크게 열어볼 수 있습니다. 확인한 쿠폰은 만료일 순으로 정렬하며 만료 전 알림을 설정할 수 있습니다. 금액권은 사용한 금액을 직접 차감해 기록하세요.

사진과 바코드는 기기에서 분석합니다. 로그인 없이 사용할 수 있으며 앱 자체의 클라우드 동기화는 제공하지 않습니다. 보관한 복사본은 사진 보관함의 원본을 삭제하거나 사진 접근을 변경해도 앱에 남습니다.

사용 완료 상태와 금액권 잔액은 사용자가 기록합니다. 발행처의 실제 사용 이력·잔액과 자동으로 연동되지는 않습니다. 이미 삭제된 원본의 과거 복원은 제공하지 않습니다.

## 키워드

쿠폰,기프티콘,기프트콘,금액권,교환권,쿠폰보관함,바코드,만료알림

## 1.0 변경 내용

- 쿠폰 사진 보관, 원본 확대, 검색 및 만료일 정렬
- 인식 실패 직접 등록과 여러 바코드 선택
- 상품 가격·할인 금액·금액권 잔액 구분
- 가져오기 대기 사진의 재시도·직접 등록·삭제
- 만료 알림 설정 및 사용 상태에 따른 예약 갱신

브랜드/매장 로고는 사용자 개인 사진에만 포함될 수 있다. Store 마케팅에는 직접 만든 사용 불가 샘플을 사용한다. 상표 이용 허락이나 심사 승인을 획득했다고 표현하지 않는다.
